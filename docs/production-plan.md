# snowlink-studio 콘텐츠 제작 기획

작성일 2026년 10월 1일. 사용자 답변으로 확정된 제품 요구사항과 구현 제안을 구분한다. 이 문서는 카드뉴스와 썰 영상 자동화를 함께 개발하기 위한 설계이며, 아직 구현되지 않은 기능의 완료 보고가 아니다.

2026-10-04에 갱신한 [PRD](PRD.md)가 현재 구현 조사·부족한 부분·시장 근거·개발 우선순위의 기준이다. 이 문서의 사용자 확정 요구는 유지하며, [노드 워크플로 설계](node-workflow-design.md)와 [트렌드 분석·제작 근거 축적](trend-intelligence-plan.md)을 함께 적용한다.

추가 애니메이션 제작 레퍼런스를 반영한 [기능 적용 계획](animation-workflow-plan.md)은 역할별 참조 자료, 대사·행동 타이밍, 초안과 최종 후보, 여러 테이크의 구간 선택, 실제 선택 종료 프레임을 이용한 연결을 구체화한다. 기존 요구사항과 단계별 승인 원칙은 유지한다.

## 확정된 방향

- 카드뉴스와 썰 영상을 함께 개발한다.
- 본인만 사용하는 개인 도구이며, 팀·외부 고객용 회원가입·권한·결제 기능은 개발 범위에서 제외한다.
- AI 대화로 시작해 누적 근거와 채널 설정을 사용하는 노드 초안을 구성하고 사용자가 수정한다.
- 조회수가 높은 콘텐츠의 주제·후킹·전개를 출처와 확인 범위에 연결해 축적하고 실제 새 기획·원고의 입력으로 사용한다.
- 여러 YouTube 채널과 Instagram 계정을 연결한다. 주 시청자, 언어, 스타일, 운영 목표는 채널별 설정으로 관리한다.
- 웹의 메모리 기반 AI 대화에서 제작 세션별로 주제와 원고 방향을 정한다. 트렌드 탐색 결과를 세션으로 가져올 수 있어야 한다.
- 캐릭터 운영은 채널별로 자유롭게 설정한다. 고정 캐릭터, 여러 캐릭터, 작품별 신규 인물을 모두 지원한다.
- 썰 영상은 원고에서 시퀀스를 나누고, 캐릭터 시트와 각 시퀀스의 베이스 이미지를 만든 뒤 실제 영상으로 생성한다.
- 숏츠는 30~60초를 기준으로 채널마다 길이와 음성 방식을 설정한다.
- 긴 영상 모드에서는 30~60초 구간을 만들고 웹에서 연속 재생한다. 이전 구간의 마무리를 토대로 다음 구간을 생성한다.
- 카드뉴스는 트렌드, Instagram 계정의 성격과 대상에 맞춰 기획한다. 분량은 주제별로 제안하고 조정하며 영상 원고 재사용은 세션별 선택 사항이다.
- 원고, 캐릭터, 장면 이미지, 완성본을 각각 승인한다.
- 하루 목표는 썰 영상 1개와 카드뉴스 3개. 전체 작업실 합계인지 채널별 목표인지는 추가 결정이 필요하다.
- 장면당 자동 재생성은 최대 3회. 최초 생성 1회와 재생성 3회로 해석한다. 모두 실패하면 사용자 검토로 전환한다.
- GPT OAuth와 Grok OAuth를 사용한다. 음성은 우선 Grok 영상의 동시 음성 생성을 검토한다.

## 채널과 제작 세션

외부 로그인 계정과 발행 채널은 별도 데이터로 관리한다. 하나의 로그인에서 여러 채널이 보이더라도 게시 대상은 플랫폼의 고유 채널 ID로 명시한다. 화면에서 채널을 전환할 때 다른 채널의 기획 메모리나 캐릭터가 섞이지 않아야 한다.

설정 적용 순서는 `작업실 기본값 → 채널 설정 → 제작 세션 설정 → 시퀀스 또는 카드별 변경`이다. 세션을 만들 때 적용된 설정을 복사해 버전을 저장한다. 이후 채널 기본값을 수정해도 진행 중인 작품이 조용히 바뀌지 않는다.

| 대상 | 저장할 정보 |
| --- | --- |
| 플랫폼 연결 | 플랫폼, 외부 계정 ID, 사용 가능한 채널, 연결 상태, 만료·재인증 상태, 서버의 자격증명 참조 |
| 채널 | 플랫폼 채널 ID, 표시 이름, 시청자, 언어·지역, 주제 범위, 스타일, 캐릭터 정책, 음성 정책, 게시 시간대, 제작 목표 |
| 제작 세션 | 채널 ID, 형식, 대화 기록, 결정 요약, 트렌드 출처, 주제, 원고 버전, 적용 설정 버전, 제작 상태 |
| 메모리 | 채널의 고정 규칙, 세션의 확정 결정, 미확정 제안, 금지·제외 항목, 근거 메시지 ID |
| 캐릭터 | 정체성 ID, 외모·의상·체형·목소리, 시트 버전, 사용 가능 채널, 표정·포즈 이미지 |

AI 대화는 원문과 요약을 함께 보관한다. 사실, 사용자 확정 결정, AI 제안을 분리하고 사용자가 메모리를 편집·삭제할 수 있게 한다. 한 작품의 임시 설정을 채널 메모리로 승격할 때에는 대상과 변경 내용을 보여준다. 모델을 바꿔도 대화 기록과 승인 이력은 유지한다.

대화에는 관련 트렌드·후킹 분석과 추천 이유를 제공한다. 원고에 채택한 참고 사례와 분석 버전은 ResearchBundle로 고정한다. 원본 공개 지표, 영상에서 관찰한 구성, 성공 원인에 대한 추정을 구별한다. 자신의 게시 결과와 사용자 평가는 다음 세션의 참고 자료로 연결하고 원본 자료는 수집 경로별 갱신·보관 조건을 적용한다.

## 썰 영상의 제작 단위

`작품 → 구간 → 시퀀스 → 생성 컷 → 테이크`로 나눈다.

- 작품: 한 편의 숏츠 또는 긴 영상 전체.
- 구간: 긴 영상의 30~60초 단위. 숏츠는 보통 하나의 구간이다.
- 시퀀스: 이야기의 의미 단위. 같은 사건이나 감정의 흐름을 담으며 여러 컷으로 나눌 수 있다.
- 생성 컷: 모델이 한 번에 생성할 수 있는 길이에 맞춘 실제 작업 단위.
- 테이크: 같은 컷을 재생성한 후보. 선택된 테이크만 최종 편집에 포함한다.

30~60초는 완성 구간 길이이며 한 번의 API 호출 길이로 가정하지 않는다. 현재 연결된 로컬 영상 모델 목록은 생성 길이를 1~15초로 보고한다. 실행할 때 모델의 실제 지원 길이, 해상도, 참조 이미지·음성 입력 능력을 다시 확인한다.

### 제작 흐름

1. 채널을 선택하고 트렌드 또는 자유 대화로 세션을 시작한다.
2. 목표 시청자에 맞춰 도입, 사건, 감정 변화, 결말을 기획하고 원고를 승인한다.
3. 시퀀스별 등장인물을 추출한다. 기존 캐릭터를 배역에 연결하거나 새 시트를 만들고 승인한다.
4. 원고를 시퀀스·생성 컷으로 분리하고 예상 대사 길이와 영상 길이를 맞춘다.
5. 캐릭터 시트와 배경 설정을 참조하여 컷별 베이스 이미지를 생성한다. 사용자가 장면 이미지를 승인한다.
6. 승인된 이미지, 캐릭터 참조, 행동·카메라·음성 지시를 넣어 실제 움직이는 영상을 만든다.
7. 대사 누락, 인물 불일치, 화면 왜곡, 음성 끊김 등을 검토한다. 필요한 컷만 재생성한다.
8. 구간별 미리보기와 전체 연속 재생으로 연결을 확인하고 자막·음량·전환을 조정한다.
9. 완성본 승인 후 지정한 채널의 게시 대기열에 넣는다.

### 시퀀스 명세

| 항목 | 목적 |
| --- | --- |
| 원고 구간과 사건 | 어떤 문장을 어떤 행동으로 보여주는지 연결 |
| 등장인물과 시트 버전 | 배역, 외모, 의상, 표정과 참조 이미지 고정 |
| 배경과 시간 | 장소, 조명, 시간대, 소품의 일관성 |
| 시작 상태 | 인물 위치, 시선, 손에 든 물건, 카메라 위치 |
| 행동과 감정 변화 | 움직임의 시작·전개·끝, 표정 변화 |
| 촬영 지시 | 화면 크기, 앵글, 이동, 구도, 피해야 할 동작 |
| 대사와 음성 | 화자, 언어, 정확한 대사, 억양, 말하기 구간, 효과음 |
| 종료 상태 | 마지막 프레임, 인물 자세, 소품, 다음 장면으로 넘길 행동 |
| 생성 설정 | 인증 연결, 기획 모델, 이미지 모델, 영상 모델, 길이, 해상도 |
| 결과와 검토 | 베이스 이미지, 테이크 목록, 선택 테이크, 승인 버전, 실패 사유 |

캐릭터 시트는 정면·측면·전신·표정 등의 기준 자료다. 실제 영상의 첫 프레임에는 여러 각도가 배열된 시트 대신 해당 장면을 완성한 베이스 이미지를 쓴다. 시트는 정체성 참조, 베이스 이미지는 구도·행동 시작점 참조로 역할을 구분한다.

얼굴·전신·의상·배경·음성 참조를 역할별로 배정한다. 시작 이미지 고정과 다중 참조는 현재 생성 모드가 다르므로 모두 동시에 적용된다고 가정하지 않는다. 모델과 입력 방식에 따른 조합 검증은 추가 기능 계획의 capability 계층에서 다룬다.

### 긴 영상의 연결

구간 A를 재생한 뒤 선택된 마지막 컷의 실제 편집 종료 시각에서 프레임과 연결 정보를 추출한다. 원본 테이크를 잘라 썼다면 원본 파일의 마지막 프레임을 쓰지 않는다. 다음 구간 B의 기획 입력에는 이 프레임, 캐릭터 버전, 의상·소품·위치, 직전 대사, 미해결 사건, 카메라 상태를 넣는다. 시간·장소가 달라지는 전환이면 이어지는 동작 대신 전환 의도를 명시한다.

모델이 지원하면 첫·마지막 프레임 고정 또는 영상 연장 기능을 사용한다. 지원하지 않으면 마지막 프레임을 다음 컷의 이미지 입력으로 활용하고 연결 검토를 거친다. 단순히 이전 영상을 참고했다고 표시하는 것으로 완료 처리하지 않는다.

웹 플레이어에는 구간 목록, 현재 구간, 전체 시간축, 이전 끝과 다음 시작 비교, 연속 재생, 특정 컷 교체 기능을 둔다. 미리보기는 선택된 클립을 순차 재생하고, 최종 출력은 해상도·프레임률·오디오를 맞춰 하나의 파일로 합친다. 브라우저 연속 재생과 최종 파일 출력을 별도 상태로 관리한다.

## 카드뉴스 제작

채널의 대상·언어·브랜드 규칙과 선택한 트렌드로 메시지를 정한다. 표지의 핵심 약속, 카드별 한 가지 주장, 근거·예시, 마지막 행동 유도 문구를 계획한다. 카드 수는 주제의 설명량·근거·가독성에 맞춰 콘텐츠마다 제안한다. 채널 템플릿은 비율·여백·문장 밀도와 허용 범위를 제공하며 사용자는 카드 합치기/나누기로 분량을 조정한다.

흐름은 `소재 선택 → 근거 확인 → 카드별 문안 승인 → 필요시 캐릭터 승인 → 시각 자료·배치 승인 → 묶음 미리보기 → 완성본 승인 → 예약 게시`다. 캐릭터를 쓰지 않는 정보형 카드뉴스는 캐릭터 단계를 적용 없음으로 명시한다.

본문 글자는 가능하면 별도 텍스트 레이어로 합성한다. 그림 안에 긴 문장을 생성시켜 문구 수정마다 이미지를 다시 만들지 않도록 한다. 채널별 글꼴, 여백, 색상, 제목 길이, 문장 수, 출처 표기를 템플릿으로 관리하고 모바일에서 잘림과 가독성을 확인한다.

같은 소재를 썰 영상과 카드뉴스로 확장할 수 있지만 각각의 원고와 승인 상태를 가진다. 일일 카드뉴스 제작 목표와 게시물 하나의 장수를 분리해 집계한다. 카드뉴스를 주제와 무관하게 세 장으로 고정하지 않는다.

## 모델과 음성

OAuth는 인증 수단이며 모델이나 생성 기능 자체가 아니다. 인증 연결과 작업 역할, 모델 능력을 각각 관리한다.

현재 ima2 코드에서 GPT OAuth 이미지 경로는 선택한 GPT 모델이 이미지 프롬프트를 기획하고 `gpt-image-2`가 실제 이미지를 렌더링하는 두 단계다. Direct 모드에서는 기획 단계를 건너뛴다. 설정에 기획 모델과 실제 렌더러를 구별해서 보여준다. 공식 API의 이미지 모델 목록을 이 OAuth 경로에서 모두 사용 가능하다고 표시하지 않는다.

Grok Imagine Video 1.5는 대사·효과음·환경음을 영상과 함께 생성한다. 이 기능을 우선 사용하되 정확한 원고 재현, 한국어 발음, 여러 컷의 목소리 일관성, 음악 중복은 검증 항목이다. 별도 TTS가 필요해져도 사용자 동의 없이 다른 유료 제공자로 전환하지 않는다. [xAI 공식 설명](https://x.ai/news/grok-imagine-video-1-5)

역할별 설정은 기획, 대화·편집, 이미지 기획·생성, 영상 생성, 음성 정책으로 나눈다. 채널 기본값과 작품별 변경을 모두 지원하도록 확장한다. 생성 기록에는 실제 요청 모델과 사용한 인증 연결의 ID를 남기며 토큰은 포함하지 않는다.

## 승인과 수정

원고, 캐릭터, 장면 이미지, 완성본 승인은 각각 특정 버전에 연결한다. 원고를 수정하면 영향을 받는 시퀀스와 후속 산출물을 재검토 대상으로 표시한다. 캐릭터 시트를 바꾸면 그 버전을 사용하는 장면에 영향을 표시한다. 승인된 다른 컷을 일괄 삭제하거나 재생성하지 않는다.

대화 편집은 “3번 시퀀스의 인물을 민수로 바꾸고 마지막 2초에 문을 닫아줘” 같은 지시를 수정안으로 만든다. 대상, 변경 전후, 재생성이 필요한 컷, 연결에 영향을 받는 다음 컷을 보여주고 적용한다. 되돌리기는 기존 테이크 선택과 승인 상태를 복원할 수 있어야 한다.

테이크는 전체 선택뿐 아니라 구간별 채택을 지원한다. 낮은 해상도 초안과 고화질 재생성은 서로 다른 후보이며 같은 연출이 보존된다고 보장하지 않는다. 초안 수정과 고화질 재생성 모두 기존 컷의 자동 재생성 상한 3회에 포함한다. 대사·반응 시점과 컷 경계의 음성·인물 상태도 검토한다.

## 운영과 게시

매일 목표량을 만들되 승인이 밀린 콘텐츠를 임의로 게시하지 않는다. 채널별 시간대와 게시 슬롯에 승인된 완성본을 배치한다. 중복 게시 방지 키는 채널 ID, 완성본 버전, 발행 작업 ID를 포함한다. 업로드가 불확실하게 종료되면 원격 게시물 상태를 조회한 후 재시도한다.

재생성 상한 3회와 통신 장애 재시도는 구분해서 표시한다. OAuth 만료, 사용량 제한, 모델 미지원은 자동 재생성을 소모하지 않고 대기·재인증 상태로 처리한다. 업스트림이 이미 생성한 작업은 작업 ID로 조회하여 중복 생성을 피한다.

AI OAuth와 YouTube·Instagram 게시 OAuth는 서로 다른 연결이다. 실제 채널 연결과 업로드 구현은 플랫폼 앱 등록, 권한, 리디렉션 주소와 자격증명 설정을 필요로 한다. 현재 연결 완료로 표시하면 안 된다.
